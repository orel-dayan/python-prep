# String Exercises

Self-contained pytest exercise around simple string utility functions, with its own
`pytest.ini` (independent from the repo root config).

## Files

- `string_utils.py` — Utility functions: `reverse_text`, `count_words`, `is_palindrome`,
  `truncate`.
- `test_string_utils.py` — Parametrized tests for each utility function.
- `pytest.ini` — Local pytest configuration for this exercise folder.

## Running

```powershell
python -m pytest Exrcise_string
```
